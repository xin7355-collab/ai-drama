# AI 劇本工坊：設計說明

## 核心判斷

AI 短劇的瓶頸不是「文字夠不夠多」，是三件事：

1. **角色一致性**：同一個人每一鏡長得一樣。靠固定的英文外觀錨點＋固定服裝＋定裝照。
2. **單鏡長度**：多數 AI 影片工具一段 5～10 秒，所以故事最後一定要拆成 5～10 秒的鏡頭。
3. **前 3 秒**：直式短劇前 3 秒沒抓住就被滑走，每集要先設計鉤子再寫劇情。

所以流程是「先設定、再分集、再分鏡」，小說版是可選的中間產物，不是主線。
小說擅長心理描寫，但心理描寫拍不出來；直接寫小說再硬轉，常常整段要重寫。

## 資料物件（對象）

| 物件 | 為什麼需要 | 關鍵欄位 |
|---|---|---|
| 企劃 | 定方向，所有 AI 指令都會帶上 | 類型、集數、每集秒數、一句話故事、賣點 |
| 風格 | 讓每張圖同一個質感 | 畫風、色調、光線、提示詞開頭／結尾、負面提示詞、單鏡上限秒數 |
| 角色 | 一致性的核心 | **外觀錨點（英文）**、服裝（可多套）、聲線、秘密、弧線 |
| 場景 | 背景一致 | **空間描述（英文，不放人）**、光線、環境音 |
| 道具 | 連戲與伏筆 | 外觀、持有人 |
| 分集 | 節奏 | **前 3 秒鉤子**、衝突、反轉、**結尾懸念**、目標秒數、小說版（可選） |
| 分鏡 | 生成單位 | 秒數、場景、時段、景別、角度、運鏡、出場角色＋服裝、畫面、英文畫面／動態描述、對白、音效、進度 |

欄位定義只寫在 `core.js` 的 `SPEC` 一處；表單、AI 指令的欄位規則、模板都從它產生，不會各自走樣。

## 畫面結構（1.3 起）

使用者最常卡在「做完這一步，下一步是什麼」，以及「AI 給的回覆要貼哪裡」。所以 1.3 把 6 個分頁收成 4 個，照製作順序排：

| 分頁 | 放什麼 | 由哪些舊功能合併 |
|---|---|---|
| 流程 | 最上面是**通用貼上框**（任何一步、任何 AI 的回覆都貼這裡，一貼上就先預覽會改什麼）；下面是 6 個步驟，自動算出「下一步」並展開那一張；第 1 步裡收著故事範本、企劃欄位、風格設定；最下面是全劇健檢 | 舊的「企劃」、企劃裡的風格、全劇健檢 |
| 角色 | 角色卡、場景卡、道具卡（下拉切換）。卡片有照片縮圖與缺項標記，打開後最上面是參考圖與參考圖提示詞 | 舊的「設定」 |
| 分集 | 集數清單 → 點一集直接看那一集的分鏡；那一集的匯出（提示詞包、字幕、分鏡表、劇本）與更多 AI 工作都收在同一頁 | 舊的「分集」「分鏡」，以及「匯出」裡的單集項目 |
| 工具 | AI 工具官方網址、常用生圖／影片工具 | 不變 |

右上角「AI 助手」會依所在位置預選工作（流程頁選下一步、角色頁選生成設定集、單集頁選拆這集分鏡）。
左上角「專案」選單放整個專案的事：切換專案、備份（含照片）與還原、匯出整部、復原匯入、刪除。

刪掉的：「空白模板」與「範本庫」下載（App 內已能直接挑範本，`templates/` 仍由 `npm run templates` 產生）、
「複製設定集」與「設定集」下載合成一個「複製設定集」、匯出分頁的「範圍」下拉（單集的在單集頁、整部的在專案選單）。

## 範本庫（`presets.js`）

沒有想法、或不想每個角色都從零寫的人，直接從範本開始：

| 範本 | 數量 | 在哪裡用 |
|---|---|---|
| 故事範本 | 14 種類型，各附一句話故事、賣點、4 組鉤子與 4 組懸念靈感、建議班底 | 流程 → 1. 故事與角色 →「從故事範本開始」；分集大綱編輯器裡也看得到同類型的鉤子靈感 |
| 角色原型 | 39 個（都市愛情、職場、懸疑、古裝、仙俠、重生復仇、家庭、校園、科幻） | 角色 →「從範本加入」 |
| 服裝 | 61 套，8 類 | 角色編輯器 →「從服裝範本加入」 |
| 場景 | 38 個，英文只寫空間、不放人 | 角色 → 切到「場景」→「從範本加入」 |
| 道具 | 25 個，寫外觀與狀態 | 角色 → 切到「道具」→「從範本加入」 |
| 畫風 | 16 種（寫實、港片霓虹、古裝、日系動畫、國漫厚塗…） | 流程 → 1. 故事與角色 → 風格與提示詞設定 →「套用畫風範本」 |
| 外觀錨點選單 | 11 個下拉（性別、年齡、臉型、髮型、辨識特徵…） | 角色編輯器 →「用選單產生外觀錨點」 |

寫範本的規則（`tests/presets.test.cjs` 會擋）：

- 外觀錨點只寫**看得見、換衣服也不變**的特徵，而且每人都有一個辨識特徵（痣、疤、眼鏡）；不寫 beautiful、elegant 這種模型每次會重新詮釋的形容詞。
- 場景的英文不能出現人，否則背景板會跟角色搶臉。
- 寫實與動畫畫風的負面提示詞不同，套用畫風時一起換。
- 每個故事範本的角色、場景、畫風都必須真的存在於範本庫。

來源：角色工坊的選項、畫風句與「保留長相」指令改寫自同作者的「咒語盒」（xin7355-collab/prompt）；定裝照配方、首幀與影片提示詞規則取自 skl 的 short-drama 系列技能（`.claude/skills/short-drama-*`）。全部內容都是重新以台灣繁體撰寫。
`templates/範本庫.md` 由 `npm run templates` 產生，不用 App 也能直接複製。

## 定裝照與參考圖

AI 短劇最常見的失敗是同一個人每鏡長得不一樣。最有效的做法是**先做定裝照，之後每鏡都拿它當參考圖**：

1. 角色卡最上面的「定裝照提示詞」：臉部、全身、三視圖、表情九宮格四種。一張只放一個人、一套服裝，均勻正面光、素色背景，不要標籤文字（模型會把字畫進圖裡）。場景卡、道具卡也有對應的參考圖提示詞（場景不放人、道具不放手）。
2. 生好的圖存到手機相簿，再按卡片上的「存入照片」：照片縮到長邊 1600px 存進 IndexedDB（`photos.js`；localStorage 只有約 5MB，放不下照片），卡片會顯示縮圖，備份檔也會帶著照片。
3. 存入第一張定裝照時，「生圖參考圖」自動改成「定裝照」：有角色出場的鏡頭，圖片提示詞最前面會加上「照參考圖保留長相、髮型與服裝」。分鏡編輯器會列出這一鏡要上傳哪些參考圖，點縮圖就能存回相簿、到生圖工具選它。
4. 「流程」第 3 步會顯示幾位角色已經有定裝照；還沒做就提醒，但不擋住後面的步驟。

影片提示詞依 short-drama-video-prompts 的規則組：動作與鏡頭 → 對白掛上說話的人（影片模型不認得人名，用外觀錨點第一段指稱）→ 沒說話的人嘴唇閉合 → 不要字幕 → 秒數。配音另外做的話，「影片提示詞的對白」選「不帶」，只留嘴型提示。

## AI 常見穿幫與對策

生圖、生影片模型每次都從頭畫，不記得上一鏡長怎樣，所以穿幫要靠「每鏡都寫一樣的字」和「自動檢查」擋下來：

| 常見錯誤 | 為什麼會發生 | App 怎麼擋 |
|---|---|---|
| 寫字、看手機時，字朝著觀眾而不是朝著角色 | 模型看過的圖大多是「字正對鏡頭」，預設就把字轉向觀眾 | 分鏡的「文字朝向」：字朝角色（鏡頭在對面，只看到倒過來的紙或手機背面）／字朝鏡頭（只能配過肩、主觀、俯拍）／不露字。動作或英文描述寫到寫字、文件、手機、螢幕卻沒選，會提醒；字朝鏡頭卻用平視也會提醒。要讓觀眾讀到的字一律後製加 |
| 主角對上敵人時，敵人裡也有一個主角 | 提示詞裡只有主角的長相描述，模型拿它去畫畫面裡的每一張臉 | 分鏡的「其他人（英文）」寫敵人、路人的外型（不同髮型、服裝、面罩）；提示詞自動加「每個角色只出現一次」和「其他人的臉、髮型、服裝都跟主角明顯不同」。動作寫到敵人、人群卻沒寫其他人，會提醒 |
| 衣服每鏡不一樣 | 只寫服裝名稱，或圖生影片時沒再寫一次 | 服裝的英文描述同時寫進圖片和影片提示詞（逐字相同）；同一場戲中間換裝會提醒 |
| 武器、道具換手、變形、憑空消失 | 道具沒有固定描述，影片幾秒後就開始變形 | 分鏡的「道具」掛上設定集的道具，寫拿法（in his right hand）；外觀描述自動帶進圖片和影片提示詞，並寫「不換手、不變形、不消失」。同一場從右手換左手、上一鏡還拿著這鏡沒掛上、動作寫到道具卻沒掛上，都會提醒 |
| 受傷、淋濕後下一鏡又好了 | 狀態只寫在動作裡，下一鏡沒延續 | 出場角色的「狀態（英文）」跟著角色進提示詞 |
| 同一場戲光線、背景跳來跳去 | 每鏡分開生成 | 同一場換場景或換時段會提醒；要換就分場 |
| 聲音每集像換了人、每鏡配樂不同 | 會出聲的影片工具每次重挑嗓子與配樂 | 角色的「配音音色」固定一個（例：ElevenLabs 自建音色），提示詞包每句都標聲線與音色；有台詞卻沒寫聲線或音色會提醒。影片提示詞每句帶聲線、只留場景的環境音，一律「不要配樂」，配樂後製統一加 |
| 同框沒說話的人也在動嘴 | 模型讓畫面裡每個人一起講話 | 影片提示詞寫「沒說話的人嘴唇閉合」，旁白鏡頭寫「畫面裡的人不說話」 |
| 畫面出現字幕或亂碼字 | 模型會把台詞燒成字幕 | 影片提示詞一律「不要字幕」，字幕用匯出的 .srt |

這些規則也寫進了 AI 拆分鏡指令，所以 AI 回傳的分鏡會直接填好道具、狀態、其他人與文字朝向；「審稿」也會多檢查一項「AI 常見穿幫」。

## 製作流程（「流程」分頁的 6 步）

1. **故事與角色**：AI 生成設定集，或挑故事範本整套套用。先寫好大綱、後補角色也可以：設定集指令會要求 AI 照大綱補齊人物與場景。
2. **分集大綱**：AI 寫分集大綱；寫完可以再跑「審分集大綱」抓前後矛盾，AI 附上的修改直接貼回匯入。
3. **角色定裝照**（建議）：見上一節。
4. **拆分鏡**：一集一集拆成 2～10 秒的鏡頭，對白每秒不超過約 4 字；流程頁會直接給「AI 拆第 N 集分鏡」。
5. **生成畫面與影片**：每一鏡複製圖片提示詞生出關鍵畫面，再用那張圖貼影片提示詞做圖生影片，做完改進度。
6. **配音、字幕、剪輯**：配音照提示詞包的聲線與音色，匯入字幕（.srt），照分鏡表時間碼排片。

「下一步」由 `core.js` 的 `flowSteps` 算：第一個還沒完成的步驟；定裝照是建議步驟，已經開始拆分鏡就不再把它標成下一步，免得卡住不想做的人。
貼上框的預覽由 `preview` 在專案複本上試匯入，所以按「匯入」前就知道這段是什麼、會改什麼、會不會出錯；匯入後「去看結果」依資料本身決定去哪一頁。

要用哪個影片工具、免費額度與費用，見 [AI影片工具與費用.md](AI影片工具與費用.md)。

## 工具分頁與劇本

- 「工具」分頁：寫劇本、生圖、生影片、配音與對嘴、配樂、剪輯、畫質提升七類，點一下另開官方網站。
  網址都查證過是官方網域（AI 影音工具的山寨站很多），中國公司的標「中國廠牌」；查不到官方來源、已關閉的服務不放。
  AI 助手的「複製指令」下面有常用聊天 AI 的按鈕；分鏡編輯器有「開生圖」「開影片」，用的是工具分頁設定的常用工具。
- 「複製劇本」：單集在那一集的「匯出這集」裡，整部在「專案 → 匯出整部」。劇本是純文字（場次標題、畫面、出場、道具、對白、音效、鉤子與懸念），
  沒拆分鏡的集會輸出大綱與小說版，可以直接貼給任何 AI 或傳給別人看。

## App 的取捨

- **不接 AI API**：用「複製指令 → 貼到 Claude／ChatGPT → 貼回結果」。不用金鑰、不用付 API 費用、哪家模型都能用。代價是要多兩次複製貼上。
- **資料只存手機瀏覽器**（文字在 localStorage、照片在 IndexedDB）：免帳號、可離線。代價是清除 Safari 資料就不見，所以「專案 → 備份專案」要定期做；備份檔會連照片一起存。專案做了一陣子還沒備份，流程頁會提醒。
- **匯入有容錯**：AI 回覆夾說明文字、```json 圍欄、尾逗號、字串裡直接換行、用名字代替 id、選項寫英文（close-up）都能讀；真的讀不了會說要怎麼叫 AI 重給。
- **匯入可復原**：每次 AI 匯入前存一份快照，「復原這次匯入」一鍵回去。
- **自動檢查**：缺外觀錨點、對白太長唸不完、超過單鏡秒數、同框超過 3 人、參照不存在、缺鉤子或懸念都會提醒。
