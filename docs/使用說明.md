# AI 劇本工坊：使用說明（iPhone）

網址：https://xin7355-collab.github.io/ai-drama/

第一次用 Safari 打開後，按分享 →「加入主畫面」，以後從主畫面開：可以離線用，資料也比較不會被系統清掉。

## 記住一件事：照「流程」頁的「下一步」做

打開 App 的第一頁是「流程」，6 個步驟裡標著綠框「下一步」的那一張會自動展開，裡面的黑色按鈕就是現在要按的。

1. 故事與角色
2. 分集大綱
3. 角色定裝照（建議做）
4. 拆分鏡
5. 生成畫面與影片
6. 配音、字幕、剪輯

## 跟 AI 來回的固定動作

1. 按步驟裡的「AI ……」按鈕（例如「AI 寫分集大綱」），跳出 AI 助手。
2. 按「複製指令」，再按下面的「開 Claude」「開 ChatGPT」「開 DeepSeek」等按鈕，到那邊貼上送出。
3. AI 回完後，把回覆**整段**複製（說明文字、```json 都沒關係）。
4. 回到 App，貼到 AI 助手的框，或「流程」頁最上面那個框。**一貼上就會先告訴你**這段是什麼、會改什麼、有沒有問題。
5. 沒問題就按「匯入」。匯入錯了按「復原這次匯入」，或到「專案」選單按「復原上一次 AI 匯入」。

自己在其他 AI 寫好的東西（例如用 DeepSeek 寫的分集大綱）也一樣：整段貼到「流程」頁最上面的框就好。

## 每一頁放什麼

| 分頁 | 用來做什麼 |
|---|---|
| 流程 | 貼 AI 回覆、看下一步、改故事設定與畫風、看全劇健檢 |
| 角色 | 角色卡、場景卡、道具卡（上面的下拉切換）。缺什麼會標紅字 |
| 分集 | 點一集就看到那一集的分鏡；一鏡一鏡複製圖片與影片提示詞；那一集的匯出在頁面下方 |
| 工具 | 各家 AI 工具的官方網址按鈕，標「中國廠牌」的是中國公司 |

左上角「專案」：切換專案、**備份**、還原、匯出整部、刪除。

## 角色卡與定裝照（讓同一個人每鏡長得一樣）

1. 「角色」分頁點一個角色，最上面是「定裝照」。
2. 複製下面的「定裝照提示詞」，按「開生圖」到生圖工具生一張，存到手機相簿。
3. 回到角色卡按「存入照片」選那張圖。卡片會出現縮圖，之後備份也會帶著照片。
4. 之後在分鏡編輯器裡，會列出這一鏡要上傳的參考圖；點縮圖可以存回相簿，到生圖工具上傳。

## 一鏡的做法

1. 「分集」→ 點一集 → 分鏡卡按「圖片提示詞」複製 → 到生圖工具貼上（有定裝照就一起上傳）→ 生出這一鏡的第一個畫面。
2. 按「影片提示詞」複製 → 到影片工具上傳剛剛那張圖、貼上 → 生成。
3. 做完把那一鏡的進度改成「完成」，「流程」頁的進度會跟著走。

## 剪輯

那一集頁面最下面「匯出這集」：下載字幕 .srt、提示詞包（配音的台詞、聲線、音色都在裡面）、分鏡表。到剪映或 CapCut 匯入字幕，照分鏡表的時間碼排片。

## 備份（很重要）

資料只存在這支手機。「專案」→「備份專案（含照片）」→ 存到「檔案」或傳給自己。換手機或清 Safari 前一定要做；很久沒備份，「流程」頁會提醒。

## 常見狀況

| 看到什麼 | 怎麼辦 |
|---|---|
| 找不到 JSON | 貼到的不是 AI 的完整回覆，回去整段重新複製 |
| JSON 不完整 | AI 回覆被截斷：叫 AI「繼續」，把兩段接起來再貼 |
| 專案裡還沒有角色 | 先貼了大綱沒關係：到「流程」第 1 步按「AI 生成設定集」，AI 會照大綱補齊角色與場景 |
| 分鏡總長和目標差很多 | 大綱改過、舊分鏡沒跟著改：那一集重新「AI 拆分鏡」 |
| 這個瀏覽器不能存照片 | 可能是無痕模式；改用一般模式，或從主畫面打開 |
| 匯入錯了 | 「復原這次匯入」或「專案 → 復原上一次 AI 匯入」 |
